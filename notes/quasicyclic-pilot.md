# Bounded construction pilot

The identity block guarantees full generator rank. Each extra block is circulant, built from a seeded random row. The pilot enumerates all nonzero messages for a candidate distance. This is not an independent verification, a fresh table comparison or a submission.

A production run must first name fresh census targets, pin the tool commit, state a trial budget, and send every candidate through both independent checkers. Candidate files remain outside codes/ until those checks pass. Nothing is sent to the table maintainer by this tool.
