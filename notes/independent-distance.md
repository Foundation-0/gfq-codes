# Distance by zero coordinates

Let G have rank k. A nonzero message u produces a codeword vanishing on a coordinate set S exactly when the corresponding columns of G impose fewer than k independent constraints on u. Thus d is n minus the largest such set. The checker enumerates coordinate sets in descending size and uses exact field elimination. It shares no implementation with the word-enumeration checker.

Time is exponential in n. The subset budget is a resource limit, not a proof of any bound. CI agreement awaits the first checker draft.
