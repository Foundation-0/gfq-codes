# Exact bounded distance checker

The checker enumerates q^k words and uses O(kn) matrix memory. It accepts only full-rank matrices. A budget error supplies no distance conclusion. The default moduli follow codes/README.md; degree-two and degree-three moduli are checked for roots, which is sufficient for irreducibility in these degrees.

The controls include every supported field and the documented tetracode. Large-code fixtures and a faster method remain open. The checker does not replace the separately reviewed upper-bound checkers.
